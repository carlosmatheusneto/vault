# Properties
- Number of edges
	- N nodes = N - 1 edges
- Depth of a node
	- Length of the path from the root to the node. Each edge adds 1 unit to length
- Height of a tree
	- Length from root to any the deepest leaf
- Degree of a node
	- Number of subtrees attached to it (number of childrens it has)
	- Degree of a tree is the maximum degree among all nodes
