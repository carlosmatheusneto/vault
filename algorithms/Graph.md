# Representation of Graph
- Adjacency Matrix Representation
	- represents a graph using a VxV matrix of 0's and 1's
- Adjacency List Representation
	- vector of lists to represent the graph
	- size of the vector equals to number of vertices
	- each index represents a vertex

# Traversal methods
- There's different ways of traversing the graph with different utilties
- The two main ones are [[Depth First Search]] and [[Breadth First Search]]
